# Шаблон карточки нозологии — корпус ON QOL
**v0.1 · август 2026 · утверждается на аппендиците**

Карточка — единица корпуса. Одна нозология = одна карточка. Тренажёр не имеет права выдать в кейсе цифру, препарат или тактику, которых нет в карточке выбранного уровня ресурса.

---

## Поля карточки

| № | Поле | Что внутри | Обязательно |
|---|------|-----------|-------------|
| 1 | `id` | Машинный ключ: `app-acute`, `chole-acute`, `pud-perf` | да |
| 2 | `Название` | Русское название + МКБ-10 | да |
| 3 | `Источник` | Гайдлайн, год, DOI. Если источников >1 — иерархия: какой главный | да |
| 4 | `Дата ревизии` | Когда сверялось. Карточка старше 24 мес = флаг «просрочена» | да |
| 5 | `Определение и подтипы` | Неосложнённая / осложнённая и по каким критериям делим | да |
| 6 | `Диагностика — ядро` | Что применимо на любом уровне: анамнез, осмотр, шкалы | да |
| 7 | `Диагностика по уровням` | Таблица basic / limited / enhanced / maximal | да |
| 8 | `Тактика по уровням` | Таблица basic / limited / enhanced / maximal | да |
| 8а | `Сила рекомендации` | У каждого тактического утверждения — маркер `[СИЛЬНАЯ]` / `[УСЛОВНАЯ]` + уверенность доказательств. Различие принципиально: условная допускает обоснованное отклонение, сильная — нет. Без маркера тренажёр учит догме | да |
| 9 | `Антибиотики` | Классы и длительность. Конкретные препараты — локальная адаптация | да |
| 10 | `Ловушки` | Типовые резидентские ошибки. Это то, чему тренажёр учит | да |
| 11 | `Красные линии` | Что нельзя ни на каком уровне. Жёсткий запрет для генератора | да |
| 12 | `Особые популяции` | Беременность, дети, ≥65, иммуносупрессия, ожирение | если есть в гайдлайне |
| 13 | `Что генератор НЕ придумывает` | Список полей, где модель обязана брать значение из карточки дословно | да |
| 14 | `Ревью` | Кто, когда, статус: draft / reviewed / approved | да |

## Уровни ресурса — рамка BHGI

| Уровень | Определение для корпуса | Типовой аналог в РК |
|---|---|---|
| **basic** | Клинический осмотр, базовый ОАК, открытая хирургия, общая анестезия. УЗИ может отсутствовать или быть без круглосуточного оператора. КТ нет | Районная больница |
| **limited** | + УЗИ круглосуточно, базовая биохимия, лапароскопия эпизодически, антибиотики широкого спектра | Городская / межрайонная |
| **enhanced** | + КТ круглосуточно, лапароскопия рутинно, ОРИТ, интервенционная радиология в рабочее время | Областная |
| **maximal** | + КТ/МРТ круглосуточно, ИР круглосуточно, специализированные бригады, микробиология с антибиотикограммой | Республиканский центр |

Правило генератора: кейс на уровне `basic` не может содержать КТ. Если тактика гайдлайна требует недоступного ресурса — карточка обязана описать, что делать вместо (fallback), а не молчать.

## Уровень обучающегося

Не PGY. В РК резидентура по хирургии 3 года, в NUSOM — 5 лет; PGY-номер не сопоставим между программами и внутри одной страны.

Пилот: **уровень A — junior.** Функциональное определение: резидент, который ассистирует и оперирует под непосредственным контролем, самостоятельно не принимает решение об операции.

Задел на расширение (не в пилоте): **B — оперирует типовое самостоятельно, решение согласовывает**; **C — принимает решение о тактике, оперирует осложнённое**. Карточка уже сейчас пишется так, чтобы уровень B/C можно было включить без переписывания корпуса: поля «Ловушки» и «Тактика» размечаются тегом сложности `[A]` / `[B]` / `[C]`. В пилоте генератор берёт только `[A]`.

## Формат ревью

Каждая карточка внизу несёт блок:

```
Ревью:
  Первичное:  Каукенова Б.Н. — [дата] — draft
  Независимое: [ФИО, место работы] — [дата] — approved / замечания
  Замечания:  [текст, построчно, с указанием поля]
```

Статус `approved` ставит только независимый рецензент. Карточка без `approved` не попадает в продакшн-корпус — тренажёр читает только approved-карточки. На пилоте допустим режим `reviewed-internal` с явной плашкой в интерфейсе: «содержание не прошло независимую верификацию».

**Открытый риск (зафиксирован):** независимого рецензента пока нет. Первичное ревью — Бота. Пока имя во второй строке не появилось, продукт нельзя показывать за пределами контролируемой группы.
