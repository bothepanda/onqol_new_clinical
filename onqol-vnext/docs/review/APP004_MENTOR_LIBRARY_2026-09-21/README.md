# APP-004: пакет знаний для свободного диалога наставника

Дата: 21 сентября 2026. Версия: 0.2. Статус: **K01–K06 и K12 утверждены для внутреннего экспериментального диалога APP-004 на русском; K07–K11 остаются draft**.

Пакет подготовлен для обсуждения взрослого стабильного неосложнённого аппендицита в APP-004. Он предлагает конкретные знания, границы их применения и разговорное поведение наставника. Семь разрешённых карточек подключены к экспериментальному диалогу; действующие клинические правила сохраняются.

## Что проверять

1. [Карточки знаний](CLAIMS.md): 12 коротких предложений с источниками и ограничениями; решение принимается по каждой карточке.
2. [Расхождения и решения](DECISIONS.md): 8 вопросов, которые нельзя разрешить простым объединением книг.
3. [Диалог](DIALOGUE.md): 8 синтетических примеров поведения, требования к памяти и проверке ответа.
4. [Реестр источников](sources.json): издания, ISBN, переносимые artifact ID, SHA-256 и номера PDF-страниц.
5. [Лист утверждения](review-decisions.json): заполняемые решения по всем карточкам и спорным вопросам.

## Предлагаемый состав

| ID | Источник | Роль |
|---|---|---|
| CAM14 | Cameron, Current Surgical Therapy, 14-е издание, 2023; Appendicitis: Diagnosis and Management, печатные с. 281–285 / PDF 325–329 | Справочное объяснение диагностики и вариантов лечения |
| DV3 | de Virgilio / Grigorian, Surgery: A Case-Based Clinical Review, 3-е издание, 2026; глава 23, печатные с. 333–344 / PDF 329–340 | Объяснения механизмов, дифференциальное мышление, структура вопросов |
| OX3 | Oxford Cases in Medicine and Surgery, 3-е издание, 2025; глава 16, изученные фрагменты PDF 639–649 | Обсуждение диагностических гипотез и цели обследований |

Номера PDF — порядковые, начиная с 1, именно для файлов из реестра. Для Oxford печатная пагинация не подтверждена; ссылка должна включать главу и PDF-страницу, а не вымышленную печатную страницу. В Cameron двухколоночная верстка: извлечённый текст нельзя считать готовыми фрагментами для поиска без восстановления порядка колонок.

В пакет входят авторские краткие пересказы и указатели, а не копии глав. Полнотекстовый индекс и передача книг провайдеру не выполнялись. V1-сессии не использованы как медицинское доказательство или источник оценочных правил.

## Область применения

Текущий файл `src/content/diseases/appendicitis/phenotypes.yaml` задаёт взрослый диапазон 18–58 лет. Этот пакет не расширяет популяцию и не создаёт педиатрические, беременные, осложнённые или нестабильные сценарии. Дифференциальные диагнозы можно обсуждать в утверждённом объёме, но обсуждение не создаёт их у пациента.

Факты книжных пациентов, результаты исследований, частоты осложнений и ответы на лечение не становятся фактами APP-004. Книга не доказывает, что конкретный симптом уже выявлен у симулируемого пациента. Для персонализированного объяснения нужна раскрытая информация из движка.

## Что считается утверждением

По Клиническому контракту v1.1 (§§5–8, 13, 20) и Контракту наставника v1.1 (§§3, 13, 17) каждая карточка должна получить именованного рецензента, дату, область, решение и версию; для высокорисковых правил требуется соответствующая независимая проверка. Решения пользователя от 21.09.2026 записаны в `review-decisions.json`: семь карточек имеют scoped approval и включены только для внутреннего эксперимента. Авторитет и дата книги не заменяют решение по конкретному утверждению.

Утверждение карточек фонового объяснения не разрешает дозировки, смену лечения, пороги безопасности или оценивание. Действующие утверждённые правила проекта сохраняют собственные источники и проверки применимости; пакет не заменяет их.

## Рекомендуемый первый объём

Предлагаю рассмотреть K01–K06 для объяснений и контекстных вопросов. K07–K11 оставить на отдельное решение по тактике, сверку с действующими правилами и полными актуальными рекомендациями. K12 описывает принцип построения обсуждения, а не обязательный набор исследований.

WSES 2025 уже фигурирует в текущем `rules.yaml`; при проверке библиографии подтверждено издание в JAMA Surgery от 1 марта 2026, 161(3):283–295, DOI [10.1001/jamasurg.2025.6218](https://doi.org/10.1001/jamasurg.2025.6218), [PubMed](https://pubmed.ncbi.nlm.nih.gov/41604201/). В этом пакете проверены библиография и аннотация, не вся таблица рекомендаций: новые детальные правила из аннотации не выводились.

## Чего пакет ещё не делает

Реализован отдельный диалоговый путь с семью карточками, историей, раскрытыми фактами, структурной проверкой и отдельным запросом проверки содержания. Полнотекстового retrieval нет. Проверка моделью не гарантирует медицинскую корректность. Клиническая готовность пилота и качество живого диалога не подтверждены; см. IMPLEMENTATION.md.

## Обратная связь по пакету

Пользователь приняла остальное содержание пакета с двумя правками: вопрос в примере 2 должен поддерживать синтез данных, а реестр источников — не содержать абсолютных локальных путей. Обе правки внесены. Файлы теперь идентифицируются через `source_id`, SHA-256 и `artifact_id` вида `sha256:<digest>`; привязка к локальному хранилищу не входит в переносимый пакет.

По сообщению пользователя, SHA-256 CAM14 и DV3 независимо сверены и совпадают с реестром. Для Oxford 3-го издания проверено соответствие содержания PDF 639–649 ссылкам пакета; SHA-256 проверенной пользователем копии не подтверждён. Сохранённый хеш OX3 относится к исходному файлу, прочитанному при подготовке пакета, и не означает побайтовой идентичности другой копии.

Эта обратная связь зафиксирована как принятие пакета с редакционными правками и проверка источников; она не подменяет отдельные решения по открытым клиническим вопросам D01–D08.
