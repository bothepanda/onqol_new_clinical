# APP-004: аудит динамических клинических величин

Дата 2026-09-25. Scope: `onqol-vnext` / APP-004 / Reference Hospital / стабильный неосложнённый взрослый 18–58. Проверены актуальные четыре контракта, `ONQOL_SPECS_README.md`, V2 governed-variability report/calibration spec, семь собираемых YAML, общий формуляр, generator, scheduler, treatment/recovery/discharge, persistence и старые APP004 review-решения. Этот файл описывает **текущее** состояние; предложения отдельно в `src/content/diseases/appendicitis/review/calibration-proposals-v1.json`.

**Разночтение старых документов.** `APP004_DISCHARGE_REVIEW_TABLE.md` (2026-08-25) называет все клинические критерии inert/pending; более поздний актуальный YAML содержит `approved_for_training` для формулировок, но `runtime_evaluation: unavailable_without_recovery_calibration` для большинства. Авторитет для этой волны — актуальный объект + recorded review, а не устаревшая таблица. `trajectories.yaml` также содержит исторический комментарий о file-level «nothing authoritative», который не соответствует утверждённым `TRJ-STABLE` и postop-модели; исходный runtime контент не правится в этой волне.

**Причинность.** Природный курс, фактическое лекарство/инфузия, завершение операции, postoperative milestone и осложнение должны оставаться отдельными событиями с собственными source ID, seed и временем. Ни одно предложенное число не допускается в исполняемый bundle без отдельного обзора. Клинико-техническое ограничение этой волны: источники поддерживают путь/направление, но не индивидуальные кривые, поэтому A=0.
