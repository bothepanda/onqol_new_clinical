# Журнал тестовых сессий ON QOL

Одна запись = одна пройденная сессия тренажёра. Журнал нужен, потому что
воспроизводимость держится на паре «preset + effective seed», а вывод сессии
(что сломалось, что решено) иначе остаётся только в памяти автора.

Правила записи:

- **Проверяемое** (дата, ветка, коммит, seed, режим, статус тестов) заполняется
  из репозитория и не обсуждается.
- **Наблюдения** заполняет тот, кто вёл сессию. Пока строка помечена
  `⚠️ черновик`, она не является фактом и ни на что не ссылается.
- Каждое наблюдение обязано закончиться одним из трёх: правка в `src/clinical/`,
  строка в `NEXT_SPRINT.md`, или новая/уточнённая строка в
  `CLINICAL_DECISIONS_REQUIRED.md`. Наблюдение без адресата — не наблюдение.

### Решения, принятые по итогам сессии

Решение автора по итогам TS-01: механизм «переспросить назначение» должен быть
общим, а не заплаткой на обезболивание и инфузию. Реализовано как реестр, к
которому действие подключается одной строкой.

Открыто и вынесено в очередь: **CDR-17** — состав обязательных слотов и
формулировки, которыми команда переспрашивает. Тексты сейчас
`reviewed_provisional_unvalidated`.
