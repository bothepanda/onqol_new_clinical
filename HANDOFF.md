## 2. Что такое V3 и зачем он

Три поколения тренажёра живут в одном репозитории:

| Версия | Как открыть | Суть |
|---|---|---|
| V1 | `?version=1` | Разговорный. Модель сама сочиняет кейс, находки и разбор. Живой, но правдоподобная ошибка неотличима от правды |
| V2 | `?version=2` | Источник истины вынесен в данные, семантический роутер. Честный, но немой |
| V2.5 | `?version=2.5` | Тот же движок, что V3, но наставник выключен. Стенд для сравнения |
| **V3** | **по умолчанию** | Ядро универсальных действий + канал наставника |

**Задача V3** — вернуть то, что нравилось в V1 (система говорит «стоп» рано,
знает про согласие и анестезиолога, одобряет «зову старшего»), не возвращая
выдуманные факты.

**Принцип: свобода в форме, жёсткость в содержании.** Наставник свободен в том,
*как* и *когда* говорить. Он несвободен в том, *что* утверждать.

## 3. Почему V2/V2.5 молчали — четыре места в коде

Это диагноз, который стоит помнить, чтобы не откатиться:

1. **Словарь мира = один файл кейса.** `semanticRouter.js:22` собирал
   `allowed_concepts` из `acuteAppendicitis.js`. Согласия, анестезиолога и вызова
   старшего там нет → `invalidConcepts` → `unknown` → тишина.
2. **Ответ собирался ножницами.** `simulatorAgent.js` склеивал реплику только из
   текстов, скопированных из карточки. Собственная формулировка модели
   отбрасывалась.
3. **Поощрение запрещено регуляркой.** `PREMATURE_TEACHING_RE` роняла ответ на
   словах «правильно» и «верно».
4. **Вся разговорная поверхность — три строки** в `closingPrompt`.

Регрессионный тест на пункт 1 живёт в `coreLibrary.test.js` под именем
`the same input is rejected without the core library - this is the V2 failure`.

## 4. Что построено

### `src/clinical/core/` — ядро универсальных действий

14 действий, общих для любой нозологии: согласие, оповещение анестезиолога и
операционной, чек-лист ВОЗ, оценка риска, ВТЭ, повторная оценка витальных,
распознавание сепсиса, вызов старшего, вызов реанимации, признание
неопределённости, структурированная передача, объяснение пациенту,
документирование.

Словарь роутера = ядро ∪ нозология ∪ кейс.

### `src/clinical/core/mentorBrief.js` + `mentorAgent.js` — канал наставника

Наставник получает **бриф**, а не карточку. Бриф — детерминированная структура:
типизированные ходы, вердикты, авторский текст, `just_performed`. Фактов
пациента в нём нет вовсе, поэтому слить их архитектурно невозможно.

Шесть ходов: стоп по предусловию, зрелая эскалация, преждевременная эскалация,
названная неопределённость, действие вне библиотеки, недоступный ресурс.

Без модели наставник говорит теми же шаблонами — тренажёр не немеет никогда.

### `src/clinical/corpus/base/manifest.yaml` — базовый слой «Б»

11 статей StatPearls: семиотика, техника осмотра, структура анамнеза,
коммуникация, предотвращение ошибок. Тир «Б» **учит, но не может быть правильным
ответом** — то же правило, что у T3 в PRD.

### `src/clinical/v3/caseFactory.js` — три клинических решения в одном месте

`V3_OPERATIVE_ACTION_IDS`, `V3_MINIMUM_ASSESSMENT`, `V3_BASE_EVIDENCE`.
Все три идут рецензенту.

## 5. Инварианты — не ломать

| Инвариант | Держится тестом |
|---|---|
| Наставник не получает фактов пациента | `the brief carries verdicts, never patient facts` |
| Наставник не подтверждает диагноз до разбора | `the mentor may not confirm the diagnosis before debrief` |
| Наставник **может** хвалить поведение | `the mentor may affirm professional behaviour` |
| Наставник не приписывает резиденту пол | `the mentor never assigns the learner a gender` |
| Наставник не велит уже сделанное | `the mentor prompt states that those actions are already answered` |
| Ядро не двигает балл до подписи рецензента | `core actions do not move the score before clinical review` |
| Тир «Б» не бывает правильным ответом | `a base-layer fact can never become the scored correct answer` |
| Кейс главнее ядра | `the case wins: core never overwrites a case-owned action` |
| Каждая ссылка тира «Б» есть в манифесте | `every tier-B citation traces back to a source in the manifest` |
| Блокирующее предусловие останавливает **до** действия | `operating without consent is stopped out loud` |

Ещё одно правило, теста на которое нет: **не выдумывать библиографию.** Где
точная строка не сверена — стоит `NEEDS_SOURCE_VERIFICATION`. Где сопоставление
с КП РК не делалось — стоит `КП?`, а не `КП−`.

### Лицензионный блокер монетизации

StatPearls под **CC BY-NC-ND**. NC конфликтует с B2C-подпиской из PRD. Для
бесплатного пилота нормально. Записано в `license_review` манифеста, идёт юристу
вместе с точками `КП!`. Поэтому `ingest_fulltext: false` у всех источников: это
ссылка для резидента и сверка для автора, а не индекс.
